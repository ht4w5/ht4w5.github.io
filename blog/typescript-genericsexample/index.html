TypeScript Generics Demystified

2025-04-18
typescriptprogrammingtype-theory

Generics are TypeScript’s most powerful feature for writing reusable, type-safe code. Let’s build up from basics.

Basic Generics#

function identity<T>(value: T): T {
  return value;
}

const num = identity(42);      // type: number
const str = identity("hello"); // type: string

TypeScript infers T from the argument — no need to specify it explicitly.

Constraints#

Limit what types a generic accepts:

function getProperty<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}

const user = { name: "Alice", age: 30 };
const name = getProperty(user, "name"); // type: string
const invalid = getProperty(user, "email"); // Error!

Conditional Types#

Branch on types:

type IsString<T> = T extends string ? "yes" : "no";

type A = IsString<string>;  // "yes"
type B = IsString<number>;  // "no"

Real-World Example: API Response Wrapper#

type ApiResponse<T> = {
  data: T;
  status: number;
  timestamp: string;
};

async function fetchJson<T>(url: string): Promise<ApiResponse<T>> {
  const response = await fetch(url);
  const data = await response.json();
  return { data, status: response.status, timestamp: new Date().toISOString() };
}

// Usage
interface User { name: string; email: string; }
const result = await fetchJson<User[]>("/api/users");
// result.data is typed as User[]

Generics turn TypeScript from a linter into a real type system.

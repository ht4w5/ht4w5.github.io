Why I Built My Blog with a Static Site Generator

2025-01-20
webastro

In an era of Next.js, Remix, and server-side everything, I chose to build my blog as a static site. Here’s why.

The Requirements#

A blog needs:

  • Fast page loads
  • RSS/Atom feed
  • Good SEO
  • Easy to deploy
  • Low maintenance

A static site delivers all of these with zero runtime infrastructure.

Why Astro#

I considered Hugo, Eleventy, and Astro. I picked Astro because:

  • I already know JavaScript/TypeScript
  • The content collections API is excellent
  • It generates zero JS by default (islands architecture)
  • The DX is great

What I Don’t Need#

  • User authentication
  • Database
  • Server-side rendering
  • Real-time features

If you don’t need dynamic server-side behavior, a static site is almost always the right choice for a blog. It’s faster, cheaper, and simpler.

Git Worktrees: The Feature I Ignored for Years

2025-02-28
gittools

For the longest time, I used git stash and git checkout to switch between branches. Then I discovered worktrees and felt silly for not trying them sooner.

What Are Worktrees?#

A worktree lets you check out multiple branches simultaneously in separate directories, all linked to the same repository:

git worktree add ../my-feature-branch feature/my-feature

This creates a new directory ../my-feature-branch with that branch checked out, while your main working directory stays on whatever branch it was on.

Why I Use Them#

  • PR review: Check out someone’s PR branch without stashing my work
  • Long-running builds: Keep a build running in one worktree while editing in another
  • Context switching: Jump between tasks without losing state

Cleanup#

git worktree list
git worktree remove ../my-feature-branch

It’s one of those git features that’s been stable for years but rarely shows up in tutorials.

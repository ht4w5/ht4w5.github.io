SSH Tips and Tricks

2025-03-28
terminaltoolsnetworking

SSH is more than ssh user@host. A few config tweaks can save you hours of typing.

Multiplexing Connections#

Add this to ~/.ssh/config to reuse connections:

Host *
  ControlMaster auto
  ControlPath ~/.ssh/sockets/%r@%h-%p
  ControlPersist 600

The first connection takes normal time. Subsequent connections to the same host are instant.

Jump Hosts#

Access internal servers through a bastion:

Host internal-server
  HostName 10.0.1.50
  User admin
  ProxyJump bastion.example.com

Now ssh internal-server transparently hops through the bastion.

Agent Forwarding (Carefully)#

Forward your SSH agent to avoid copying private keys:

ssh -A user@remote

⚠️ Only use this on trusted servers — root on the remote can use your forwarded agent.

Port Forwarding#

Forward a remote service to your local machine:

# Access remote database locally
ssh -L 5432:localhost:5432 user@db-server

Now psql -h localhost connects to the remote database.

SSH Keys Best Practices#

# Generate a modern key
ssh-keygen -t ed25519 -C "your@email.com"

# Use ssh-agent
eval "$(ssh-agent)"
ssh-add ~/.ssh/id_ed25519

Ed25519 keys are shorter, faster, and more secure than RSA.

SSH config is one of those “set it and forget it” productivity tools.

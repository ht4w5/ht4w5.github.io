Making This Blog: Design Decisions

2025-01-18
webdesignastro

I wanted a blog that felt like reading a mailing list archive — plain, fast, and focused on text. No hero images, no card layouts, no animations.

The Inspiration#

Sites like lkml.org and early web archives have a quality that modern blogs lost: they load instantly and let you focus on the content. The browser’s default styling is surprisingly good when you don’t fight it.

Design Principles#

  1. No JavaScript by default — The site works without JS. Search is a progressive enhancement.
  2. System fonts + serif — Noto Serif for body text, Noto Sans Mono for code. Fast to load, readable everywhere.
  3. Single column — No sidebars, no distractions. 720px max-width.
  4. Monospace nav links — [posts] [about] [tags] — functional, not decorative.

What I Left Out#

  • Dark mode toggle (respects prefers-color-scheme if I add it later)
  • Share buttons
  • Comments (use RSS and reply on your own blog)
  • Analytics (I don’t need to count visitors)

The result is a blog that feels like it could have existed in 2005, but builds with modern tooling. I’m happy with the trade-off.

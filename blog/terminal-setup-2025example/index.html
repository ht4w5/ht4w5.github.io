My Terminal Setup in 2025

2025-02-15
toolsterminal

I’ve been meaning to document my terminal setup for a while. Here’s what I use daily.

Terminal: WezTerm#

After years of iTerm2, I switched to WezTerm. It’s cross-platform, configured in Lua, and has excellent multiplexer support built in.

-- wezterm.lua (excerpt)
local wezterm = require 'wezterm'
local config = wezterm.config_builder()

config.font = wezterm.font('Noto Sans Mono')
config.font_size = 13.0
config.color_scheme = 'Catppuccin Mocha'

return config

Shell: Fish#

Fish gives me autosuggestions and syntax highlighting out of the box. No plugin manager needed.

Utilities#

  • eza — modern ls with colors and icons
  • ripgrep — faster grep
  • fd — faster find
  • bat — cat with syntax highlighting
  • zoxide — smarter cd

The whole setup is reproducible with a dotfiles repo and takes about 10 minutes to bootstrap on a new machine.

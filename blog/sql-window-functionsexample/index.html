SQL Window Functions: The Feature Most Developers Skip

2025-02-20
databaseprogramming

Most developers learn GROUP BY and stop there. Window functions are the next level — they let you compute aggregations without collapsing rows.

The Basic Pattern#

-- Regular GROUP BY: collapses rows
SELECT department, AVG(salary)
FROM employees
GROUP BY department;

-- Window function: keeps all rows
SELECT name, department, salary,
       AVG(salary) OVER (PARTITION BY department) as dept_avg
FROM employees;

The second query gives you every employee’s salary and their department’s average, on the same row.

Practical Examples#

Running total#

SELECT date, amount,
       SUM(amount) OVER (ORDER BY date) as running_total
FROM transactions;

Ranking within groups#

SELECT name, department, salary,
       RANK() OVER (PARTITION BY department ORDER BY salary DESC) as dept_rank
FROM employees;

Year-over-year comparison#

SELECT year, revenue,
       LAG(revenue) OVER (ORDER BY year) as prev_year,
       revenue - LAG(revenue) OVER (ORDER BY year) as yoy_change
FROM annual_revenue;

When to Use Them#

Window functions shine when you need:

  • Running totals or moving averages
  • Rankings within groups
  • Comparing rows to adjacent rows (LAG/LEAD)
  • Percentile calculations

They’re available in PostgreSQL, MySQL 8+, SQLite 3.28+, and every major database. No excuse not to learn them.

Linux Process Management Essentials

2025-01-30
terminaldevops

Every Linux user interacts with processes, but few understand the mechanics. Let’s fix that.

Process Basics#

Every running program is a process with a unique PID:

ps aux | grep nginx

Signals#

Signals are how you communicate with processes:

SignalNumberPurpose
SIGTERM15Graceful shutdown (default for kill)
SIGKILL9Force kill (cannot be caught)
SIGHUP1Reload configuration
SIGSTOP19Pause process
SIGCONT18Resume paused process
# Graceful shutdown
kill 1234

# Force kill
kill -9 1234

# Reload nginx config
kill -HUP $(pidof nginx)

Job Control#

Manage processes from your shell:

# Run in background
long-task &

# List jobs
jobs

# Bring to foreground
fg %1

# Send to background
bg %1

# Suspend current process
Ctrl+Z

Process States#

  • R — Running or runnable
  • S — Sleeping (waiting for event)
  • D — Disk sleep (uninterruptible)
  • Z — Zombie (finished but not reaped)
  • T — Stopped

Practical: Finding Resource Hogs#

# Top processes by CPU
ps aux --sort=-%cpu | head -10

# Top processes by memory
ps aux --sort=-%mem | head -10

Understanding processes helps you debug hanging applications and runaway scripts.
